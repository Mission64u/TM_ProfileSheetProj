TM_ProfileSheetProj

HTML forms for Oxford-Miami Community Toastmasters, hosted here via GitHub Pages and embedded into the club website (oxfordoh.toastmastersclubs.org) using iframes, since the club's site platform (FreeToastHost) strips <script> tags from pasted content.

Files
index.html — New Member Profile Sheet. Submissions email to the VP Education (vpe-2846914@toastmastersclubs.org) and also log to a Google Sheet.
Membership.html — Membership Application form. Submissions email to the VP Membership (vpm-2846914@toastmastersclubs.org).
Live URLs
New Member Profile Sheet: https://mission64u.github.io/TM_ProfileSheetProj/
Membership Application: https://mission64u.github.io/TM_ProfileSheetProj/Membership.html
Notes
Payment card numbers are intentionally not collected through the Membership Application form — applicants are directed to provide card details directly to a club officer instead.
To update either form, edit the file in VS Code, save, then commit and push (Source Control panel → Commit → Sync Changes).
